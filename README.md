# World Safety For All 🌍

**Tagline:** Har Jaan Keemti Hai - Ek Bhi Jaan Na Jaye

### Ye kya hai?
`World Safety For All` ek free, offline chalne wali single-file app hai.  
Iska maksad hai: Prakritik + Manav har problem me turant sahi jankari aur helpline dena.  
Koi login nahi, koi data nahi, koi paise nahi. **Sabke Liye - For All**

### Kis-kis ke liye banaya hai?
Ameer, Gareeb, Bhookha, Bebas, Bhikhmanga, Student, Gaon, Sheher - **Har Insaan ke liye**

### Features - v2.1
#### 🚨 Turant Madad
- 1 Click Call: 112 Police, 108 Ambulance, 181 Women Helpline
- Suicide Prevention Help Button

#### ⛈️ Mausam aur Prakriti
Baadh, Bhukamp, Aandhi, Toofan, Ola, Heavy Rain, Sookha, Drain Blockage

#### 🌊 Nadi aur Paani
Ganga Dirty/Clean Guide, Yamuna Clean Guide, Doobne se Bachav, Boat/Ship Safety

#### ⚠️ Accident aur Dusre Khatre
Road Accident, Borewell me Bachha, Surang/Malba me Fansna

#### 🤝 Samajik Suraksha
Hinsa/Murder/Rape se Bachav Guide, Bhukhe/Bebas ki Madad

#### 🚀 Aane Wale Features
Live Alert, Crowd Report Map, Voice + 10 Bhasha

### Kaise Chalayein
1. `index.html` file download karein
2. Phone ya Computer me double click karein
3. Internet ki jarurat nahi hai

### Tech
Sirf HTML + CSS + JavaScript. Koi server nahi.
